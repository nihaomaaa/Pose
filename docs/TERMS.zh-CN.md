# Pose 使用协议与隐私提示

版本：2026-10-29.1

## 非商业使用

Pose 以公开源码形式提供，仅供非商业学习、个人研究与交流。不得销售本软件、出售使用权限、经营付费生图服务或将本项目用于商业牟利。Pose 新增代码适用 PolyForm Noncommercial 1.0.0；第三方代码、模型与图库仍适用各自许可。

## 图片来源与人物授权

仅使用你拥有或已获许可处理的图片，并取得被拍摄人物对相关处理的同意。尊重著作权、肖像权、名誉权与隐私权。“仅供学习”不能免除侵权责任。禁止未经同意的私密影像、涉及未成年人的性内容、诈骗、冒充、诽谤或其他违法用途。

## 本地与云端处理

本地生成将照片与作品保存在你选择的数据文件夹。安装时会连接运行时、模型和图库的下载服务器，对方会收到 IP 等正常网络信息。云端生成会把提示词和必要图片传给你明确选择的服务商，数据可能传往境外。使用前请了解其隐私、留存和训练政策。

## 费用、审核与生成效果

API 费用由服务商收取，网页会员未必包含 API 额度。服务商可能因内容审核拒绝请求；停止任务不一定能停止云端计费。AI 可能改变脸部、服装、身体结构和细节，请逐张检查。Pose 不承诺身份完全一致，也不绕过审核。

## AI 内容标识

生成作品不代表真实发生的事件。对外发布时，应依法主动声明 AI 生成并使用发布平台的标识功能。不得恶意删除、伪造或隐匿服务商水印及来源标识。

## 保存与删除

密钥使用 Windows 用户级安全机制加密。原图、作品与日志保存在本地数据文件夹，直到你主动删除。删除作品不会同时删除原始照片，也无法删除服务商留存的副本。卸载默认保留数据。请勿把密钥或私密照片发到 GitHub Issue。

软件按现状提供，但法律规定不得免除或限制的责任以及用户法定权利不受本协议影响。本协议不保证免除法律责任，也不能保证所有用途都合规。公开运营、商业服务或面向其他地区分发前，应另行评估适用要求。反馈可通过项目 GitHub Issue 提交，请勿公开敏感信息。
