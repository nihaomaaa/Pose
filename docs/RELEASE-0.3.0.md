# Pose 0.3.0

- Pose 全新人物图标，中英文界面，圆角下拉浮层与对齐的照片 / 姿势面板。
- 免费本地 4B、可选授权 9B、自定义兼容模型；自动识别硬件、暂停续传、实际下载速度与 ETA。
- 独立人物 A / B，多图编辑服务及文字生图适配，ComfyUI 图形化输入映射。
- API 密钥 Windows 加密、首用协议、按语言切换的区域法律参考、关于与 GitHub Star。
- 中文 / 英文 README、协议、隐私与 API 能力表。

50 项自动测试通过；RTX 4060 8 GB / 32 GB RAM 上完成 4B 双人真实出图。云端适配为协议测试，未逐家验证付费出图；9B 仍需用户在模型官方自行授权。所有生成都有概率改变脸部、服装和细节。

Pose 原创代码采用 PolyForm Noncommercial 1.0.0，非商业用途。图库与模型的独立许可见仓库文档。源码及 EXE 不包含私人照片、API 密钥、图库图片或模型权重。

## English

Download Pose-Setup-0.3.0-x64.exe and install on Windows 10/11 x64.

This release adds the Pose identity, Chinese/English UI, rounded select menus, aligned reference panels, local model preferences, resumable verified downloads with speed/ETA, provider connections, visual ComfyUI mappings, encrypted credentials, regional legal references and documentation.

50 automated tests pass. Real two-person 4B generation was verified on RTX 4060 8 GB / 32 GB RAM. Cloud adapters have contract tests, not live paid-provider certification. 9B requires the user’s own model authorization. AI identity/anatomy consistency is not guaranteed.

Unsigned Windows installer. First setup downloads large assets; allow at least 45 GB free space for default GPU mode. Mirror/fallback availability depends on the network. Cloud APIs may charge separately. Original code is source-available under PolyForm Noncommercial 1.0.0. Models and gallery artwork keep their own licenses and are downloaded separately.

See README.md, README.en.md and docs/API_SUPPORT.md for requirements and exact capabilities. SHA256SUMS.txt verifies the release assets. Locally built packages can differ from CI builds because Windows installer timestamps are not reproducible.
