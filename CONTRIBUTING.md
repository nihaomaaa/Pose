# 参与开发 / Contributing

Read both the README and LICENSE before contributing. Pose original code uses PolyForm Noncommercial 1.0.0; contributions must be compatible with that license. Dependencies and upstream artwork retain their own licenses.

Windows x64, Node.js 24: run npm ci, npm test and npm run build before submitting changes. Verify both Chinese and English, keyboard use, visible focus, rounded select popovers, image-frame alignment, reduced motion, reduced transparency and narrow layouts.

Model strategy changes must include license and download provenance, revision/file hashes, memory requirements and real-device results. Do not claim untested GPU compatibility or guaranteed face consistency. API adapters must distinguish multi-reference editing from text-to-image and include contract tests; never claim mocked tests as live paid-provider verification.

不要提交模型、Python 环境、图库图片、用户上传、生成历史、密钥、用户路径或本地日志。使用有权分享的虚构人物素材测试，不要把私人照片用于公开示例。保持人物 A、B 独立输入以及明确的同人复用选择；不要绕过服务商内容审核。
